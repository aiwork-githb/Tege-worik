# Зал у окон — вариант 2

Второй вариант расстановки тренажёрного зала гостиницы. Вариант 1 лежит в папке `../gym-design/` и не меняется.

Что изменено по сравнению с вариантом 1:

- стол для пинг-понга перенесён к окнам, на место скамьи для жима (скамья сдвинута к двери);
- беговая дорожка и эллипс стоят на прежнем месте стола, лицом к нижней стене, телевизор 55″ на этой стене перед ними, слева зеркало;
- кулер у стены санузла, дверь санузла раздвижная;
- добавлена напольная груша в правом нижнем углу;
- скамья для пресса перенесена в пристройку к турнику.

Компромисс: свободная зона 2 м за дорожкой сужает проход от входа к пристройке до 59 см.

Откройте `index.html` в браузере. Размеры в сантиметрах.
