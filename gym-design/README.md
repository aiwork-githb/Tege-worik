# Зал у окон — тренажёрный зал гостиницы

Эскизный дизайн-проект небольшого спортзала при гостинице (44,5 м² + пристройка 6,0 м²), построенный по эскизу заказчика с обмерами (`eskiz.jpg`).

Версия 2 — расстановка по списку заказчика: профессиональная беговая дорожка, эллипс, турник с брусьями, скамья для жима со стойками, мультифункциональный тренажёр, скамья для пресса, стол для пинг-понга, телевизор, колонки и столики-полки вокруг колонн.

Версия 3 — по уточнениям: потолок зала 2,4 м, стеклянная пристройка 2,8 м с проходом через бывшее окно О-3 (туда перенесены эллипс и турник на стойках), санузел вместо подсобки, раздевалка справа от входа, кулер и зеркальная стена.

Откройте `index.html` в браузере. Внутри:

1. Исходные данные: эскиз, обмерный план и как он прочитан, что проверить на объекте.
2. Концепция: высокое — в пристройку, зеркало напротив окон, вход как раздевалка, пинг-понг внизу.
3. План расстановки со слоями: зоны, безопасность и проходы, размеры, свет, инженерия.
4. 3D-вид (three.js).
5. Зоны и покрытия пола с площадями.
6. Спецификация оборудования.
7. Отделка и материалы.
8. Свет, климат, электрика, шумоизоляция.
9. Безопасность, правила зала и что изменил потолок 2,4 м.
10. Следующие шаги.

Все размеры в сантиметрах. Цифры по свету, воздуху и охлаждению предварительные и уточняются инженерным проектом.
